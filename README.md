# Capstone_project_Bauman — Классификация госконтрактов по объектам закупки


## Описание проекта

**Классификация госконтрактов по объектам закупки** — это исследовательский проект, направленный на автоматическое определение типа строительного контракта на основе текстового описания объекта закупки и сопутствующих признаков (цена, длительность и др.).  

Цель проекта — построить модель машинного обучения, способную корректно классифицировать контракты по группам, даже если код **ОКПД-2** указан неточно или отсутствует.


## Основные задачи проекта

Проект включает в себя полный цикл разработки модели классификации — от подготовки данных до экспериментов с нейросетевыми архитектурами. Основные этапы работы:

1. **Загрузка и исследование данных**  
   Импорт обработанных данных, разведочный анализ (EDA) и разбиение выборки на train / validation / test.

2. **Baseline-модель**  
   Использование TF-IDF векторизации и логистической регрессии для построения базовой модели и оценки стартового качества.

3. **Классические модели машинного обучения**  
   Эксперименты с методами TF-IDF + Random Forest и Bag of Words + Random Forest. Подбор гиперпараметров и сравнение результатов.

4. **Нейросетевые модели**  
   Разработка более сложных архитектур — создание словаря токенов, обучение RNN и LSTM моделей, работа с предобученными эмбеддингами FastText и лемматизацией (Mystem).

5. **Анализ и сравнение результатов**  
   Оценка моделей по метрикам Accuracy и F1-score, выбор наилучшего подхода и формулирование выводов.

6. **Заключение**  
   Подведение итогов, интерпретация результатов и направления для дальнейшего улучшения модели.


## Веб-приложение

В рамках проекта было разработано интерактивное веб-приложение на **Flask**,  
позволяющее вводить описание контракта, его стоимость и длительность,  
а затем получать предсказанную категорию.  

Приложение было развёрнуто на платформе **Render.com**  
(в настоящее время недоступно из-за миграции проекта с GitLab).
